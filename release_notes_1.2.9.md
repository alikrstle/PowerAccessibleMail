# Power Accessible Mail 1.2.9

## العربية

- إضافة فحص التحديثات من GitHub Releases عند بدء البرنامج ومن قائمة المساعدة.
- اختيار ملف التثبيت الصحيح تلقائيا للنسخة الكاملة أو نسخة Gmail API المحدودة.
- إضافة وضع تحديد عدة رسائل باستخدام الفأرة أو الاختصار Ctrl+Shift+Space، مع إجراءات جماعية متوافقة مع قارئ الشاشة.
- تحسين حذف الرسائل المحددة برسالة تأكيد تنطق عدد الرسائل وتنقلها إلى سلة محذوفات Gmail.
- تحسينات على مستعرض HTML والتركيز وقائمة السياق وسرعة بعض إجراءات الرسائل.
- إبقاء بيانات OAuth منفصلة بين النسخة الكاملة ونسخة Gmail API المحدودة.

ملاحظة أمنية: ملفات هذا الإصدار غير موقعة رقميا لأن شهادة Authenticode موثوقة غير متوفرة بعد. يرجى التحقق من ملفات SHA-256 المرفقة.

## English

- Added update checks through GitHub Releases at startup and from the Help menu.
- The updater automatically selects the correct installer for the full or Gmail API limited edition.
- Added multi-message selection with the mouse or Ctrl+Shift+Space, including screen-reader-friendly bulk actions.
- Improved bulk deletion with an accessible message count and Gmail Trash confirmation.
- Improved HTML message viewing, focus behavior, context menus, and the speed of several message actions.
- Kept OAuth credentials isolated between the full and Gmail API limited editions.

Security note: this release is not digitally signed because a trusted Authenticode certificate is not available yet. Verify downloads with the included SHA-256 files.
