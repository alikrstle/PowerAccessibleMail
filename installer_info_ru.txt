Информация о Power Accessible Mail

Разработано Soljan.AlSharq.
Солжан.АльШарк. принадлежит Али Аль-Амиру
Пакеты x64 и x86 предоставляют одинаковые функции.

Конфиденциальность является частью приложения

Power Accessible Mail получает доступ к Gmail через Gmail API и к Microsoft через службы Outlook только после того, как вы одобрите доступ на официальной странице входа провайдера.

Ручная настройка IMAP и SMTP также доступна, если вы выберете этот метод самостоятельно.

Учетные записи и кэшированные данные хранятся на вашем устройстве.

Конфиденциальные локальные токены учетных данных и сообщения защищены с помощью Windows DPAPI для текущей учетной записи Windows.

Ваши данные не продаются и не используются для рекламы

Когда вы запрашиваете перевод сообщения, приложение отправляет выбранный текст сообщения в Google Translate только для выполнения этого запроса.

Вы можете удалить учетную запись и ее локальный кеш изнутри приложения.
