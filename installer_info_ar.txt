معلومات البرنامج

اسم التطبيق: Power Accessible Mail
الإصدار: 1.2.9
المطور: صولجان الشرق
المالك: علي الأمير
الشركة: صولجان الشرق
ملكية الشركة: شركة صولجان الشرق تابعة للمالك علي الأمير
نوع الإصدار: نسخة Gmail API محدودة الصلاحيات

ملخص الخصوصية والملكية
- البرنامج وحقوقه مملوكة لعلي الأمير، والمطور هو صولجان الشرق.
- يصل البرنامج إلى بيانات البريد بعد موافقة المستخدم عبر OAuth لتنفيذ القراءة والإرسال وإدارة الرسائل.
- تحفظ الحسابات والكاش محليا، وتحمي البيانات الحساسة بواسطة Windows DPAPI لحساب Windows الحالي.
- لا تباع بيانات المستخدم ولا تستخدم للإعلانات.
- عند طلب ترجمة رسالة، يرسل نص الرسالة المحددة إلى Google Translate لتنفيذ طلب المستخدم فقط.
- يستطيع المستخدم إزالة الحساب وبيانات الكاش المحلية من داخل البرنامج.

راجع هذا الملخص، ثم حدد مربع الموافقة في أسفل الصفحة للمتابعة.
