Power Accessible Mail
Version: 1.2.8

Developer and owner: Ali Al-Amir
Company: Soljan.AlSharq., owned by developer Ali Al-Amir
Edition: Full IMAP and SMTP edition

Power Accessible Mail is an email client designed for screen-reader users. It supports browser or manual account setup, reading and sending messages, replies, message status management, and attachments.

Settings can switch between Arabic and English, the HTML and simple message viewers, in-view or separate-window translation, and light or dark appearance.

Privacy
Accounts and cached data are stored locally, with sensitive data protected by Windows DPAPI. User data is not sold or used for advertising. When translation is requested, the selected message text is sent to Google Translate only to perform that request. Accounts and local cached data can be removed from inside the application.

Main shortcuts
- Ctrl+N composes a message.
- Ctrl+R replies to a message.
- Ctrl+T translates a message.
- Ctrl+Space returns to the message list.
- Ctrl+Enter moves between the message and item viewers.
- F5 refreshes messages.
- F1 opens the application guide.
