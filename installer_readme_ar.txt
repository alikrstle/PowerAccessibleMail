Power Accessible Mail
الإصدار: 1.2.9

نوع الإصدار: نسخة Gmail API محدودة الصلاحيات
المطور: علي الأمير
الشركة: صولجان الشرق
ملكية الشركة: شركة صولجان الشرق تابعة للمطور علي الأمير

فكرة البرنامج
Power Accessible Mail برنامج بريد إلكتروني مصمم ليكون مريحا مع قارئات الشاشة. تعتمد واجهته على قوائم وحقول Windows الأصلية، وتعرض الرسائل عموديا لتسهيل التنقل بالأسهم.

إضافة حساب Gmail
1. افتح قسم الحسابات واختر إضافة حساب.
2. اختر التسجيل عبر المتصفح، ثم اختر Gmail.
3. أكمل اختيار الحساب والموافقة في صفحة Google الرسمية.
4. عد إلى البرنامج بعد نجاح تسجيل الدخول.

هذه النسخة تستخدم Gmail API ونطاق gmail.modify المحدود. لا يحتاج المستخدم إلى إدخال كلمة مرور Gmail داخل البرنامج.

الأقسام الرئيسية
- الرسائل الواردة: تعرض رسائل صندوق INBOX.
- الرسائل غير المرغوب بها: تعرض Spam أو Junk عند اكتشافه.
- الرسائل المرسلة: تعرض الرسائل التي أرسلها المستخدم.
- كل الرسائل: تعرض صندوق Gmail "كل البريد"، وهو مفيد للرسائل الحديثة التي لا تظهر في الوارد.

تصنيف الرسائل
يحتوي كل قسم على صندوق تصنيف لعرض كل الرسائل، أو الرسائل المميزة بنجمة، أو غير المقروءة، أو المقروءة. ويعرض خيار سلة المحذوفات الرسائل الموجودة في سلة Gmail الحقيقية.

الأوامر الأساسية
- تحديث المحتوى المعروض: يجلب أحدث الرسائل من الخادم.
- مزامنة كل الرسائل: يجلب الرسائل القديمة على دفعات ويحفظها محليا.
- تحميل رسائل أقدم: يجلب دفعة أقدم من القسم الحالي.
- خيارات الحسابات وإدارتها: لإضافة حساب أو إعادة تسجيل الدخول أو إزالة حساب من البرنامج.
- إنشاء بريد إلكتروني: لكتابة رسالة جديدة وإرسالها.
- الإعدادات: لاختيار العربية أو الإنجليزية، ونوع مستعرض الرسائل، ونمط الترجمة داخل المستعرض أو في نافذة مستقلة، والوضع الفاتح أو المظلم.

حالة القراءة
اختيار الرسالة لا يجعلها مقروءة تلقائيا. اضغط Space فوق الرسالة المحددة للتبديل بين مقروءة وغير مقروءة.

قراءة الرسائل والعناصر
في مستعرض HTML تظهر الروابط والأزرار داخل موضعها في الرسالة كعناصر حقيقية لقارئ الشاشة. استخدم Tab أو أوامر قارئ الشاشة للتنقل، ثم Enter أو Space للتنفيذ.

في وضع HTML يكون مستعرض العناصر مخفيا افتراضيا. استخدم Ctrl+Enter للتبديل بين مستعرض الرسالة ومستعرض العناصر، واستخدم Ctrl+Space للرجوع إلى قائمة الرسائل.

في المستعرض السهل يظهر نص مرتب قليل الأسطر الفارغة، ويعرض مستعرض العناصر الروابط والأزرار والمرفقات بعناوين واضحة.

إجراءات الرسالة
يمكن فتح قائمة الإجراءات من الزر المخصص أو باستخدام Shift+F10. تتضمن الإجراءات المتاحة، بحسب حالة الرسالة، الرد والتمييز بنجمة والترجمة والتثبيت في الأعلى والحذف إلى سلة Gmail وحفظ المرفقات.

الاختصارات
- Ctrl+A: خيارات الحسابات وإدارتها.
- Ctrl+N: إنشاء رسالة جديدة.
- Ctrl+R: الرد على الرسالة المحددة.
- Ctrl+T: ترجمة الرسالة الحالية.
- F5: تحديث الرسائل.
- F1: عرض دليل البرنامج.
- Ctrl+Space: الرجوع إلى قائمة الرسائل.
- Ctrl+Enter: التبديل بين مستعرض الرسالة ومستعرض العناصر.
- Shift+F10: فتح قائمة السياق والإجراءات.
- Alt+F4: إغلاق البرنامج.

الأمان والخصوصية
- يستخدم تسجيل الدخول عبر المتصفح OAuth ولا يقرأ البرنامج كلمات مرور المتصفح.
- يحفظ كاش الرسائل محليا بتشفير Windows DPAPI لحساب Windows الحالي.
- لا تحتوي نسخة التوزيع على حسابات المستخدم أو رسائله المخزنة.
- لا يستطيع البرنامج الوصول إلى Gmail إلا بعد موافقة المستخدم في صفحة Google الرسمية.

التحديث وإزالة البرنامج
لفحص التحديثات افتح قائمة المساعدة واختر تحديث البرنامج. لإزالة البرنامج افتح صفحة التطبيقات المثبتة في إعدادات Windows واختر Power Accessible Mail ثم إزالة التثبيت.
