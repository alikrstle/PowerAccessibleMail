隐私是应用程序的一部分

仅当您在提供商官方登录页面上批准访问后，Power Accessible Mail 才会通过 Gmail API 访问 Gmail，并通过 Outlook 服务访问 Microsoft

当您自己选择该方法时，也可以手动设置 IMAP 和 SMTP

帐户和缓存数据存储在您的设备上

使用当前 Windows 帐户的 Windows DPAPI 保护敏感的本地凭据令牌和消息

您的数据不会被出售或用于广告

当您请求消息翻译时，应用程序会将选定的消息文本发送到 Google Translate，仅用于执行该请求

您可以从应用程序内部删除帐户及其本地缓存
