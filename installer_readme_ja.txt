1.6.0 版の主な操作

Alt+1 は現在の分類のメッセージ一覧、Alt+2 は実際に開いた最後のメッセージのビューアー、Alt+3 はメールのセクション、Alt+4 はアプリケーションのコマンド一覧へ移動します。Alt+D は完全なショートカットガイドを開きます。一覧の横に表示されるプレビューは、開いたメッセージには数えられません。最初にメッセージビューアーへ入ってください。まだビューアーを開いていない場合、Alt+2 は先にメッセージを開くよう通知します。

設定では 3 つの検索方法を選べます。Ctrl+F は独立した検索ウィンドウを開き、検索ボタン方式は送信者と日付のフィルターを追加し、常設フィールドは入力中に現在のセクションを絞り込みます。検索対象は選択中のアカウントに現在読み込まれているメッセージで、送信者、アドレス、件名、日付、状態を照合します。本文全体や、まだサーバーにしかないすべてのメッセージを直接検索するものではありません。古いメールを探す前に、古いメッセージの読み込みまたは全メッセージの同期を行ってください。

アーカイブは、メッセージをごみ箱へ送らずに受信トレイから外します。メッセージ一覧でコンテキストメニューを開き、「メッセージをアーカイブ」を選びます。後で「アーカイブ済みメッセージ」分類から見つけ、必要なら「受信トレイに戻す」を選びます。ピン留めとアーカイブは一覧のメニューにあり、ビューアー内のメニューには一覧のすべてのコマンドが含まれません。

Ctrl+Enter で項目ビューアーを開きます。矢印キーでリンク、画像、添付ファイルを選び、アプリケーションキーまたは Shift+F10 でその項目のメニューを開いてください。Tab で「項目の操作」ボタンにも移動できます。Ctrl+Enter でメッセージに戻り、Escape でメッセージ一覧に戻ります。

作成画面の「宛先」にアドレスを入力または貼り付け、アドレス帳へ追加するボタンを実行します。アドレスだけを保存することも、任意の名前を付けることもできます。保存後も作成画面に残ります。後で「宛先」で下矢印を押し、保存した名前を選んで Enter または Space を押すと、宛先欄の内容が対応するメールアドレスに置き換わります。

Ctrl+T で受信メッセージを翻訳できるのは、フォーカスがメッセージビューアー内にあるときだけです。初回はプライバシー通知を承認し、最初に 20 の一般的な言語が並ぶ一覧から翻訳先を選びます。旧版ではアラビア語が自動選択されていたため、以前に翻訳を許可した利用者も一度だけ言語を選びます。翻訳言語はインターフェイス言語とは独立しています。

送信前の文を翻訳するには、件名または本文のコンテキストメニューから、別の言語への変換を選びます。言語の追加は保存だけを行い、翻訳は開始しません。もう一度メニューを開いて、その言語を選んでください。フィールド全体が置換され、Ctrl+Z で元の文へ戻せます。

Alt+H は対話型ガイドを開きます。31 の課題はローカルの練習用データを使い、実際のメール送信やアカウントの変更を行いません。新しい課題では複数選択、フォルダー、カスタムセクション、ローカル分類を練習できます。進捗は保存されます。更新の準備が完了すると、アプリケーションが終了して通常の対話型セットアップ画面を起動します。更新は無人でインストールされません。

メッセージを検索する

[設定] で希望の検索方法を選択します。オンデマンド検索では、Ctrl+F を押すと完全なウィンドウが開きます。これは、アラビア語キーボード レイアウトでは Ctrl+ب として表示されます。代わりに、カテゴリの横にボタンを表示したり、入力中に現在のセクションをフィルタリングする永続フィールドを表示したりできます。

検索ウィンドウには、結果リスト、メッセージ ビューア、およびアイテム ビューアが含まれています。アプリケーションによってすでにロードまたは同期されているメッセージを検索し、送信者名、電子メール アドレス、件名、日付、およびステータスを照合します。

メールへようこそ

Power Accessible Mail は、電子メールの読み書き、整理、更新をキーボードから快適に行えるように構築されています。

更新機能は Windows の証明書ストアを使用します。証明書や日時の問題は、安全な検証を無効にせずに通知します。

ネイティブ Windows のリストとフィールドにより、スクリーン リーダーが予測可能なコントロールを提供し、メッセージが垂直に配置されるため、メール内での移動が直接的で親しみやすく感じられます。

自分に合った方法でアカウントを追加してください

アカウントなしでアプリケーションが起動した場合は、Google で続行して Microsoft サインインを手動で続行するか、アカウントを追加せずにメイン インターフェイスを開くことができます

「アカウントのオプションと管理」を開き、「アカウントの追加」を選択します

3 つのサインイン方法が実際のリストとして表示されます

ブラウザ サイン イン、Google アプリ パスワード サイン イン、または高度な手動サイン インを選択し、Enter キーを押すか、選択した項目を右クリックするか、[キャンセル] の横にある [OK] ボタンを使用します。

ブラウザーのサインインでは、Google または Microsoft の公式同意ページが開きますが、アプリケーションにブラウザーのパスワードの読み取りを要求することはありません。

ブラウザーから戻った後、アプリは、「続行」ボタンと「コピー」ボタンを備えた読みやすいダイアログにサインイン結果を表示します。サインインが失敗した場合は、エラーの詳細をコピーして開発者に送信できます。サインイン トークンとシークレットは、表示またはコピーする前に編集されます。

手動サインインは電子メール サービスの選択から始まります

Google または Microsoft を選択すると、アプリケーションはフィールドを確認可能な状態に保ちながら、一致する IMAP および SMTP 設定を入力します。

対応する Gmail アカウントでは、Google のアプリパスワードによるログインをおすすめします。 2段階認証とGoogle公式ページで作成したアプリパスワードが必要です。 16 文字のコードを入力します。アプリケーションはスペースを自動的に削除し、Windows 暗号化を使用して保存します。このフィールドには通常の Google アカウントのパスワードを入力しないでください

Microsoft ブラウザの場合は、パスワード ベースの IMAP アクセスがアカウント ポリシーによって制限されている可能性があるため、サインインすることをお勧めします。

メールセクション

受信箱は実際の受信箱フォルダーを読み取ります

スパムはスパムまたはジャンクを読み取ります

送信済みには、送信したメッセージが保持されます

すべてのメールは、利用可能な場合に Gmail のすべてのメールを開き、受信トレイ ラベルが付いていない最近のメッセージを表示できます

各セクション内で、フィルターはすべてのメッセージ、スター付きメッセージ、未読メッセージ、既読メッセージ、または実際のゴミ箱フォルダーを表示できます。

最新のメッセージが必要なときはいつでも F5 キーを押してください

すべてのメッセージを同期すると、古いメールがバッチで取得され、ローカルに保存されます。

古いメッセージをロードすると、現在のセクションから古いバッチが 1 つ追加されます

好みのビューアで各メッセージを読んでください

HTML ビューアは、リンクとボタンを実際のページ要素として自然な位置に保持します。

Tab またはスクリーン リーダーの閲覧コマンドを使用してコマンドにアクセスし、Enter または Space を押してアクティブにします。

Ctrl+Enter を押して、メッセージ ビューアとアイテム ビューアの間を移動します。

Esc キーを押すとメッセージ リストに直接戻ります

簡単なビューアは繰り返しの空行を削除し、きれいなテキストを表示します。

アイテム ビューアは、リンク ボタンの画像と添付ファイルを明確な名前で収集します。

メッセージを選択しても、自動的に既読としてマークされません

通常のメッセージリストでスペースを押すと、フォーカスされたメッセージを既読と未読の間で切り替えることができます。

複数のメッセージを一度に処理する

通常モードでは、メッセージはチェックボックスのないリスト項目です。

Ctrl+Shift+Space を押して複数選択モードに入り、すべてのメッセージがチェック ボックスになります。

矢印キーで移動し、スペースを押してメッセージをオンまたはオフにするか、マウスを使用します

アプリケーションは 150 ミリ秒後にこのモードへの開始または終了を通知します。

Control を単独で押すと、選択したカウントが聞こえます

Escape または Ctrl+Shift+Space をもう一度押してモードを終了します

最初の項目の上または最後の項目の下に移動しようとすると、境界が通知されます
コンテキスト メニューには、適切な一括読み取りスター ピンとゴミ箱コマンドが用意されています。

削除では確認を求められ、ゴミ箱に移動されるメッセージの数が示されます。

キーボードから離れずに書いて操作できる

電子メールを作成すると、完全なメッセージ ウィンドウが開きます

セットアップは、Windows で利用できる電子メール アプリケーションの中に Power Accessible Mail を登録します。アプリケーションの設定から、デフォルトの電子メール アプリとして PowerAccessibleMail を選択を選択し、Windows の設定で選択を確認します。 Windows 11 では、Enter キーを押しても関連アプリ ピッカーが開かない場合があります。 MAILTO でスペースを押して開きます。その後、ブラウザで電子メール アドレスまたは mailto リンクを選択すると、受信者の件名と本文がリンクから自動的に入力されて作成が開きます。アプリケーションはユーザーの承認なしに Windows のデフォルトを変更することはありません

メッセージ一覧のメニューには、既読状態、スター、固定、アーカイブ、削除、整理の操作があります。メッセージビューアーの専用メニューには返信、コピー、翻訳、転送があります。項目ビューアーにはリンク、画像、添付ファイルのための別のメニューがあります。

メッセージ コンテキスト メニューには Shift+F10 またはアプリケーション キーを使用し、添付ファイルの画像とリンクには [アイテム アクション] ボタンを使用します。

その場で、または別のウィンドウで翻訳

Ctrl+T は、現在のメッセージを選択した翻訳言語に翻訳します

[設定] で、翻訳によって HTML または簡易ビューア内のコンテンツを置き換えるか、別のウィンドウで開くかを選択します。

翻訳は、メッセージ ビューア内にいる間のみ利用可能になります。

インターネット接続が必要で、ユーザーがリクエストした場合にのみ、選択したメッセージ テキストが公式の Google 翻訳サービスに送信されます。最初の翻訳の前に、アプリはこの転送について説明し、許可とキャンセルの選択肢を提供します。 [許可] を選択すると、言語リストが開き、最初に 20 の共通言語が表示され、その後、残りのすべての言語が表示されます。言語をクリックするか、矢印キーと Enter を使用して言語を選択します。同意と言語が保存されます

アプリケーションを自分のものにする

設定では、アラビア語、英語、フランス語、スペイン語、トルコ語、ヒンディー語、簡体字中国語、ロシア語、日本語またはドイツ語、HTML またはページ内または別のウィンドウでの簡単なメッセージ ビューアの翻訳、および明るいまたは暗い外観を選択できます。

NVDA ライブラリが通知するアプリケーション アクションの数を 4 つのレベル (なし、一部、またはすべて) で制御することもできます。レベルの横にある「アクション通知のカスタマイズと管理」ボタンをクリックすると、ネイティブ Windows チェックボックスを含むカテゴリが開きます。 Tab を使用してそれらの間を移動し、状態を聞き、Space を使用して変更し、保存します。デフォルト レベルでは、ユーザーがカスタマイズでそのカテゴリを有効にしない限り、既読または未読の状態の変更やサーバー保存の確認は通知されません。設定には、Windows 設定でアプリケーションのページを開くデフォルトの電子メール アプリとして PowerAccessibleMail を選択することも含まれています。 Enter キーが応答しない場合は、MAILTO で Space キーを押してアプリ ピッカーを開きます

選択内容は次回の起動のために保存されます

ブラウザを開かずにアップデート

アプリケーションは起動後に GitHub リリースをチェックします。ヘルプから手動でチェックしてアップデートを確認できます。

リリースが利用可能になると、アップデートにより内部進行状況ウィンドウが開き、そのバージョンのリリース日の進行状況バーとパーセンテージが表示されるようになりました。

適切なインストーラーがユーザープロファイルの Power Accessible Mail 更新フォルダーへダウンロードされ、SHA-256 ダイジェストが検証されます。その後、アプリケーションが終了して通常の対話型セットアップ画面を起動します。インストーラーの各ページに従って更新を完了してください。

メインウィンドウの詳細ガイド

アプリケーションの通知

通知バーはウィンドウの上部に表示され、完了したアクション、必要なサインイン、利用可能なアップデートなどの重要な情報を通知します。下部のステータスバーは最新の動作状態を維持しますが、一部の通知はしばらくすると消えます。

電子メールアカウントセレクター

このコントロールには、追加したアカウントがリストされます。アカウントを選択すると、そのデータを別のアカウントと混合することなく、表示されるフォルダーとメッセージが変更されます。アカウントが存在しない場合は、アカウント オプションと管理を開いてアカウントを追加します

アプリケーションコマンド一覧

表示されたコンテンツを更新すると、現在のセクションの最新のメッセージが取得され、F5 と同じアクションが実行されます。

すべてのメッセージを同期すると、古いメールがバッチで取得され続け、同期が完了するか停止するまでローカルに保存されます。

古いメッセージをロードすると、セクションに現在表示されているメッセージよりも 1 つ古いバッチが取得されます。
アカウント オプションと管理では、アカウントを追加して再度サインインするか、アカウントを削除するためのコマンドが開きます

電子メールを作成すると、新しいメッセージ ウィンドウが開きます

アドレス帳では、保存した電子メール アドレスが開き、関連メッセージの編集やピンの表示、アドレスの削除を行うことができます。

[設定] では、アプリケーション言語のメッセージ ビューアの翻訳モードと外観の選択が開きます。

メールセクション

[受信トレイの送信済みスパム] と [すべてのメール] は別個のページであり、それぞれに表示されるメッセージとフィルターが表示されます。プロバイダーがサポートしている場合はすべてのメールが利用可能で、受信トレイ ラベルが付いていないメッセージが表示される場合があります。

フィルターの選択

フィルターは、現在のセクションに表示される内容を制御します: すべてスター付き、未読、既読、または実際のゴミ箱フォルダー。 「ゴミ箱」を選択すると、実際の内容を電子メールプロバイダーに要求します

メッセージ一覧

各行にはステータス送信者の件名と日付が含まれます。ステータスは、メッセージが既読か未読かスター付きかピン留めされているかを通知します。矢印キー「Home」「End」「Page Up」および「Page Down」を使用して移動します。メッセージを選択すると内容が読み込まれますが、既読ステータスは自動的に変更されません

メッセージビューア

この領域には、設定で選択した HTML または簡易ビューアを使用して、選択したメッセージが表示されます。 Escape を押すとフォーカスがメッセージ リストに戻り、Ctrl+Enter を押すとアイテム ビューアに移動します

アイテムビューア

この個別のリストには、メッセージ リンク ボタンの画像と添付ファイルが収集されます。すべてのアイテムは、リンク 1 ボタン 1 イメージ 1 または添付ファイル 1 などのタイプと番号で始まり、その後にその名前とアドレス、またはファイルのタイプとサイズが続きます。アプリケーションは、ホストおよび共通の追跡パラメータを正規化した後、同等のアドレスを結合し、要素テキスト aria-label title または alt テキストから最適な説明を選択します。リンクとボタンは読み取り順序を維持し、その後に画像と添付ファイルが続きます。非表示の 1 by 1 トラッキング画像は除外されます

アイテムアクションボタン

メッセージ一覧のメニューには、既読状態、スター、固定、アーカイブ、削除、整理の操作があります。メッセージビューアーの専用メニューには返信、コピー、翻訳、転送があります。項目ビューアーにはリンク、画像、添付ファイルのための別のメニューがあります。

メッセージ取得の進行状況とステータスバー

進行状況コントロールは、メッセージの取得または同期の割合を報告します。ステータス バーには現在の操作とその結果が表示されるため、フォーカスを移動する必要はありません。

メッセージを既読または未読としてマークする

既読状態は設定で選んだモードによって変わります。自動モードではメールビューアに入ると既読になります。行を選ぶだけでは変わりません。手動モードではビューアを開いても既読状態は変わりません。通常の一覧では Space で既読と未読を切り替え、変更がサーバーに保存されます。

アプリケーションキーまたは Shift+F10 でコンテキストメニューを開きます。複数選択時の既読状態のコマンドはサブメニューにまとめられ、選択したメールに適用されます。

まだ注意が必要なメッセージを見つけるには未読フィルタを使用し、読み終えたメッセージを確認するには既読フィルタを使用します

アイテムビューアを段階的に使用する

フォーカスがメッセージ ビューア内にあるときに、Ctrl+Enter を押します。項目ビューアが使用可能になり、フォーカスがそのリストに移動します。上矢印と下矢印を使用して、リンク ボタンの画像または添付ファイルを選択します

Enter または Space を押して項目を直接開きます。外部アドレスを持つ安全なリンクまたは画像はデフォルトのブラウザで開き、添付ファイルはローカルで開きます。リンクのあるボタンは同じように動作しますが、開くことができるアドレスのないボタンや画像は明確にアナウンスされます。

明示的なコマンドの場合は、Tab キーを押して [項目アクション] ボタンに移動し、Enter または Space キーを押します。添付ファイルには [選択した添付ファイルを開く] と [選択した添付ファイルを保存] があり、メッセージ内のすべての添付ファイルを一度に保存できます。外部アドレスを持つリンクまたは画像は、安全なアドレスを Windows クリップボードに配置する [選択したリンクを開く] および [選択したリンクをコピー] を提供します。選択した項目に適用されないコマンドは、誤ってアクティブ化されるのを防ぐために無効のままになります。

Ctrl+Enter で項目ビューアーを開きます。矢印キーでリンク、画像、添付ファイルを選び、アプリケーションキーまたは Shift+F10 でその項目のメニューを開いてください。Tab で「項目の操作」ボタンにも移動できます。Ctrl+Enter でメッセージに戻り、Escape でメッセージ一覧に戻ります。

受信した添付ファイルを管理する

メールサービスが受信を許可している場合、受信した添付ファイルを 1 ファイルあたり最大 5 GB（5,000,000,000 バイト）までダウンロードできます。大きな添付ファイル全体をメモリに読み込まず、分割してダウンロードします。十分な空き容量があり、大容量ファイルに対応したドライブを選び、完了を待ってください。失敗したダウンロードで既存のファイルが不完全なコピーに置き換わることはありません。送信上限と画像表示の 25 MB 上限は変わりません。クラウドストレージのリンク先のファイルは対象外です。
添付ファイルを開くと、保護された一時コピーが安全な名前で書き込まれ、それをデフォルトのアプリケーションで開くように Windows に要求されます。現在のセッション用に作成された一時コピーは、Power Accessible Mail が終了すると削除されます

EXE BAT CMD や MSI などのコマンドを実行する可能性のあるファイルを開く前に、アプリケーションはセキュリティ警告を表示します (デフォルトは [いいえ])。送信者とファイルの両方を信頼できる場合にのみ続行してください

1 つの添付ファイルを保存するには、アイテム ビューアでその添付ファイルにフォーカスを当て、[アイテム アクション] ボタンに移動して、名前とフォルダーを選択する前に、[選択した添付ファイルを保存] を選択します。すべての添付ファイルを保存するには、同じボタンから [すべての添付ファイルを一度に保存] を選択し、1 つのフォルダーを選択します。リンク フォーカスをコピーするには、アイテム アクションを使用して、[選択したリンクをコピー] を選択します。アプリケーションは安全なアドレスを Windows クリップボードに置きます。ファイル名がすでに存在する場合、アプリケーションは以前のファイルを黙って置き換えるのではなく、一意の名前を作成します。

メッセージを作成し、送信添付ファイルを追加する

作成ウィンドウは「宛先」で始まり、「電子メール アドレスをアドレス帳に追加」、「件名」、および複数行の「本文」フィールドが続きます。添付ファイルを追加するには、本文の後に追加された添付ファイルのリストが続き、タブ順で送信とキャンセルを行います。

フォーカスがあるときに下矢印を押すと、保存されたアドレスが開きます。矢印キーで移動し、Enter または Space を押していずれかを選択します。選択したアドレスはフィールド内のすべてのテキストを置き換えます。フィールドが空または無効なときにアドレス追加ボタンを押すと、アプリケーションは問題を通知し、保存しません。

[添付ファイルの追加] を押してファイル ピッカーを開きます。同じ操作で 1 つのファイルまたは複数のファイルを選択できます。選択した各ファイルはファイル名とサイズとともにリストに表示されるので、送信される内容を正確に確認できます。

誤って追加したファイルを削除するには、添付ファイル リストでファイルにフォーカスを合わせて [削除] を押すか、アプリケーション キーを押して [選択した添付ファイルを削除] を選択します。リストから削除しても、元のファイルはコンピュータから削除されません。

[送信] を押すと、アプリケーションはリストにまだ表示されているすべてのファイルを MIME メッセージに追加します。これは、Gmail API アカウントと SMTP アカウントの両方で機能します。電子メール プロバイダーはメッセージと添付ファイルのサイズ制限を制御し、許容サイズを超えるメッセージを拒否する場合があります。

アドレス帳を使用する

アプリケーションコマンドリストからアドレス帳を開きます。 [新しい電子メール アドレスを追加] の横に縦​​方向のアドレス リストが表示されます。矢印キーで参照し、Enter または Space を押すか、アドレスをダブルクリックして作成を開き、受信者が自動的に入力されます

アプリケーション キーを押すか、アドレス上で Shift+F10 を押してコンテキスト メニューを開きます。電子メール アドレスを編集したり、上部に固定したりできます。固定されたアドレスの場合、コマンドは「電子メール アドレスの固定を先頭から解除」に変わります。また、送受信したメッセージを表示したり、削除したりすることもできます。関連メッセージ ウィンドウで矢印キーを使用して移動し、Enter または Space を押すと、選択したメッセージがメイン ウィンドウで開きます。

コンテキスト メニューとアプリケーション キー

アプリケーションキー（メニューキー）または Shift+F10 は、フォーカスのあるコントロールのメニューを開きます。メッセージ、フォルダー、セクション、ビューアー、送信添付ファイル、アドレス帳にはそれぞれ専用のメニューがあります。先に目的の項目へフォーカスを移してください。

メッセージビューアーのメニューは返信、コピー、翻訳、転送です。既読状態、スター、固定、アーカイブ、削除の操作はメッセージ一覧に戻って行います。リンク、画像、添付ファイルは Ctrl+Enter で項目ビューアーを開き、そのメニューまたは「項目の操作」を使ってください。

メッセージ リストでは、コマンドはフォーカスされているメッセージとその現在の状態に適応します。 [アイテム アクション] ボタンでは、選択したアイテム タイプに適応します。複数選択モードでは、メッセージ コマンドがグループに作用し、アプリケーションは削除前に影響を受けるメッセージ数を通知します。

メッセージフォルダーとローカルセクション

フォルダーには、選択したメッセージがグループ化されます。カスタム セクションは、メッセージとフォルダーのローカルな場所です。サーバー フォルダーを作成したり、プロバイダーでメールを移動したりすることはありません。メッセージ リストで Alt+Z を押し、矢印キーとスペースでメッセージを選択し、Tab キーでフォルダーを作成するか、キャンセルします。名前を入力してください。空白のままにすると、今日の日付の新しいフォルダーが使用されます。メッセージの間にフォルダが表示され、その名前、メッセージ数、作成日が表示されます。 Enter キーを押して開き、Backspace キーを押して戻ります。そのメッセージは、グループ化されている間は一般リストから非表示になります。フォルダーのコンテキスト メニューでは、固定、スター付け、名前変更、アーカイブ、復元が可能です。フォルダーを削除すると、グループのみが削除され、メッセージは削除されません。

Alt+X は、選択したメッセージを既存のフォルダーに追加します。コンテキスト コマンド [フォルダーまたはセクションにメッセージを追加] を使用すると、どちらかの宛先を選択できます。フォルダー内では、メール自体を削除せずにフォルダーから取り除けます。 Alt+C は、フォーカスされたフォルダーを削除します。 Alt+Ctrl+Z はセクションを作成します。 Alt+Ctrl+X を押すと、フォーカスされた項目がローカルのセクションに移動します。 Alt+Ctrl+C を押すと、元のメールは削除されずに、現在のカスタム セクションが削除されます。組み込みセクションは削除できません。 メッセージを元のセクションへ戻すには、そのメニューで「元のセクションに戻る」を選んでください。

カスタム カテゴリはフィルターです

カテゴリ ボックスのコンテキスト メニューを開き、[新しいカテゴリの作成] を選択するか、Alt+Ctrl+Shift+Z を押します。矢印と Enter キーを使用してフィルタを選択し、名前を入力します。このカテゴリは、メール セクション全体の使い慣れたカテゴリ ボックスに表示され、読み込まれたローカル メッセージをフィルタリングします。それは目的地ではありません。フィルターには、最近読んだメール、プロモーション メール、組織、指定された送信者アドレス、頻繁に送信する送信者、ロックされたメッセージ、メッセージ フォルダー、添付ファイルのあるメッセージ、添付ファイルのないメッセージが含まれます。送信者のドメインからの組織検出の推定値。送信者の身元は確認されません。指定した送信者の場合は、カテゴリに名前を付ける前にアドレスを入力します。

Ctrl+Down はカスタム カテゴリに移動します。 Ctrl+Up を押すと、最初の組み込みカテゴリに戻ります。 Alt+Ctrl+Shift+X で現在のカスタム フィルタを編集し、Alt+Ctrl+Shift+C で削除します。フィルタを削除してもメールは削除されません。ロックされたメッセージ フィルターはパスワードをバイパスしません。

フォルダーとセクションのパスワードロック

メッセージ フォルダーまたはカスタム セクションでコンテキスト メニューを開き、パスワード ロックを選択します。警告を読み、少なくとも 8 文字を入力し、パスワードを確認します。メッセージは通常の一覧と検索結果に表示されなくなります。パスワードと現在の Windows ユーザーの保護を使い、グループへの所属情報とローカルの内容を暗号化します。ローカル Windows アカウントは機能します。 Microsoft アカウントは必要ありません。

ロックされた項目で Enter を押し、パスワードを入力すると、そのフォルダーまたはセクション内の内容が表示されます。スコープを離れるかアカウントを切り替えると、ロック解除されたセッションが終了します。保護を完全に削除するには、[ロックの削除] を選択し、パスワードを入力します。パスワードの回復はありません。メールはプロバイダーに残りますが、ローカル組織は回復できない可能性があります。ロックは、以前にエクスポート、ダウンロード、またはバックアップされたコピー、またはプロバイダー アカウントを保護しません。ローカルの暗号化データは Windows ユーザーに関連付けられているため、別のユーザーまたはコンピュータに移植できると想定すべきではありません。ディスク暗号化を使用して、Windows セッションも保護します。

サウンドとロービジョンのオプション

設定の「アプリのサウンドをカスタマイズ」を開いてください。 イベントを個別に有効または無効にし、サウンドの名前で Enter を押すか、サウンドをクリックしてプレビューします。 Replace は MP3 ファイルを受け入れます。サウンドダイアログと設定の両方を確認して変更を保存します。キャンセルしても、以前に保存したサウンドは上書きされません。アップデートとインストーラーの BGM は固定されており、ここではカスタマイズできません。インストーラにはミュート チェックボックスがあります。

設定では「アプリのサウンドをカスタマイズ」の次に「ロービジョン向け機能とオプション」があります。 ネイティブの選択ボックスとチェックボックスは、テキストとインターフェイスのスケーリング、コントラスト、フォーカスの強調表示、アプリケーション内ポインター、テキスト/背景色を提供します。 Tab、矢印、スペースを使用してダイアログを確認し、設定を保存します。これらのオプションは、スクリーン リーダーの設定ではなく、アプリケーションの外観を変更します。

その他のナビゲーションおよび選択のショートカット
Alt+S はアドレス帳、Alt+] は次のアカウント、Alt+[ は前のアカウントです。アラビア語キーボードでは後の2つは د と ج に対応します。Alt+A はアカウント管理、Ctrl+A はフォルダーを除く表示中のメッセージの選択です。入力欄の外では Backspace が1段階戻ります。Escape はまずメッセージフォルダーまたは複数選択から出て、メイン画面へ戻るにはもう一度押すよう通知します。ビューアーではメッセージ一覧に戻ります。このガイドでは 1 が次の見出し、2 が前の見出しです。Alt+D はショートカットガイドです。

アドレス帳フォルダーのロック

Alt+S でアドレス帳を開きます。フォルダーのオプションから作成を選び、矢印と Space でアドレスを選択し、Tab で作成ボタンへ進んで名前を入力します。フォルダーは同じ一覧に表示され、中のアドレスは外側に重複表示されません。Enter で開き、Backspace で戻ります。メニューには固定、名前変更、パスワードロック、アドレスを残してフォルダーを削除する操作があります。アーカイブとスターはありません。フォルダー内では、そのオプションからアドレス自体を削除せずに外へ戻せます。新しく保存したアドレスは現在の一覧に残り、開いているフォルダーに追加されます。

アドレス帳でフォルダーのコンテキストメニューを開き、パスワードロックを選びます。名前、アドレス、固定状態が保護されますが、その人のメールは保護されません。Enter とパスワードで開きます。フォルダーが開いている間も、アドレスは一般的な宛先一覧に表示されません。フォルダー内ではアドレスの追加、編集、固定、削除ができます。アドレス自体を削除せずにフォルダーから取り除くと、一般のアドレス帳に戻ります。ロックを解除すると、アドレスはフォルダーに残ったまま一般的な宛先一覧で選択できるようになります。

アカウントを削除する前に、アドレス帳フォルダーのロックを解除してください。別のアカウントの会話フォルダーにもあるアドレスは、ロックする前にそこから取り除いてください。忘れたパスワードは復元できません。アプリ外に保存したコピーは保護されません。
