# ملف تعريف النسخة المحدودة

هذا المجلد ليس نسخة مستقلة من المصدر. ملف `run.bat` يشغل المصدر المشترك في جذر المشروع مع تفعيل Gmail API المحدود، وهوية تطبيق ومسار بيانات وملف OAuth مستقلة عن النسخة الكاملة. إعدادات الواجهة، مثل اللغة ونوع مستعرض الرسائل ونمط الترجمة والوضع المظلم، مشتركة مع النسخة الكاملة لكي يكون التصفح متطابقا.

ملفات البناء هنا تحيل إلى أداة البناء المشتركة في الجذر:

```powershell
..\build_power_accessible_mail_gmail_api_limited_64.ps1
```

أما إصدار التوزيع النظيف مع الاختبارات والمثبت والبصمات فيبنى من الجذر بواسطة:

```powershell
..\build_release_power_accessible_mail_gmail_api_limited_64.ps1
```

يجب أن يحتوي `oauth_clients.json` هنا على المفتاح `google_gmail_api` فقط.

الإصدار المحمول الحديث يوجد في `..\release\win-x64-gmail-api-limited`. مجلدات `build` و`dist` و`release` القديمة داخل ملف التعريف ليست مسارات تشغيل معتمدة.
