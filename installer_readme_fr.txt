Bienvenue dans votre messagerie

Power Accessible Mail est conçu pour rendre la lecture l'écriture l'organisation et l'actualisation des courriels confortables au clavier

Les listes et les champs Windows natifs offrent aux lecteurs d'écran des commandes prévisibles tandis que les messages sont disposés verticalement pour rendre la navigation directe et familière

Ajoutez votre compte de la manière qui vous convient

Lorsque l'application démarre sans compte vous pouvez continuer avec Google continuer avec Microsoft vous connecter manuellement ou ouvrir l'interface principale sans ajouter de compte

Ouvrez Options et gestion des comptes puis sélectionnez Ajouter un compte

Les méthodes de connexion apparaissent dans une véritable liste

Sélectionnez la connexion par navigateur ou la connexion manuelle puis appuyez sur Entrée faites un clic droit sur l'élément sélectionné ou utilisez le bouton OK à côté d'Annuler

La connexion par navigateur ouvre la page d'autorisation officielle de Google ou Microsoft et ne demande jamais à l'application de lire le mot de passe de votre navigateur

La connexion manuelle commence par le choix du service de messagerie

Sélectionnez Google ou Microsoft et l'application remplit les paramètres IMAP et SMTP correspondants tout en laissant les champs disponibles pour vérification

La connexion manuelle à Gmail nécessite généralement un mot de passe d'application

Pour Microsoft la connexion par navigateur est recommandée car l'accès IMAP par mot de passe peut être limité par la politique du compte

Les sections de votre messagerie

Boîte de réception affiche le véritable dossier de réception

Courrier indésirable affiche le dossier Spam ou Indésirables

Messages envoyés contient les messages que vous avez envoyés

Tous les messages ouvre le dossier Tous les messages de Gmail lorsqu'il est disponible et peut révéler des messages récents qui ne portent pas le libellé Boîte de réception

Dans chaque section le filtre peut afficher tous les messages les messages suivis les messages non lus les messages lus ou le véritable dossier Corbeille

Appuyez sur F5 chaque fois que vous souhaitez récupérer les messages les plus récents

Synchroniser tous les messages récupère les anciens courriels par lots et les stocke localement

Charger des messages plus anciens ajoute un lot plus ancien depuis la section actuelle

Lisez chaque message dans la visionneuse de votre choix

La visionneuse HTML conserve les liens et les boutons à leur position naturelle comme de véritables éléments de page

Utilisez Tab ou les commandes de navigation de votre lecteur d'écran pour les atteindre puis appuyez sur Entrée ou Espace pour les activer

Appuyez sur Ctrl+Entrée pour passer de la visionneuse de messages à la visionneuse des éléments

Appuyez sur Échap pour revenir directement à la liste des messages

La visionneuse simple supprime les lignes vides répétées et présente un texte clair

Sa visionneuse des éléments rassemble les liens les boutons les images et les pièces jointes sous des noms explicites

La sélection d'un message ne le marque pas automatiquement comme lu

Appuyez sur Espace dans la liste normale des messages pour basculer le message ciblé entre lu et non lu

Travaillez avec plusieurs messages à la fois

En mode normal les messages sont des éléments de liste sans cases à cocher

Appuyez sur Ctrl+Maj+Espace pour passer en mode de sélection multiple où chaque message devient une case à cocher

Déplacez-vous avec les touches fléchées puis appuyez sur Espace pour cocher ou décocher un message ou utilisez la souris

L'application annonce l'entrée dans ce mode ou sa sortie après 150 millisecondes

Appuyez uniquement sur Contrôle pour entendre le nombre de messages sélectionnés

Appuyez de nouveau sur Échap ou Ctrl+Maj+Espace pour quitter ce mode

Lorsque vous tentez de dépasser le premier ou le dernier élément l'application annonce la limite de la liste

Le menu contextuel propose les commandes groupées adaptées pour l'état de lecture le suivi l'épinglage et la Corbeille

La touche Suppr demande une confirmation et indique combien de messages seront déplacés vers la Corbeille

Écrivez et agissez sans quitter le clavier

Composer un courriel ouvre une fenêtre complète de rédaction

Répondre Suivre Traduire Épingler en haut et déplacer vers la Corbeille du fournisseur sont disponibles dans le menu contextuel du message. La liste de la visionneuse des éléments n'a pas de menu contextuel et le bouton Actions de l'élément affiche directement les commandes des pièces jointes des images et des liens

Utilisez Maj+F10 ou la touche Applications pour le menu contextuel du message et le bouton Actions de l'élément pour les pièces jointes les images et les liens

Traduction dans la visionneuse ou dans une fenêtre séparée

Ctrl+T traduit le message actuel dans la langue de l'application

Dans Paramètres choisissez si la traduction remplace le contenu de la visionneuse HTML ou simple ou si elle s'ouvre dans une fenêtre séparée

La traduction est disponible uniquement lorsque vous êtes dans la visionneuse de messages

Elle nécessite une connexion Internet et envoie le texte du message sélectionné à Google Translate uniquement lorsque vous demandez sa traduction

Adaptez l'application à vos préférences

Paramètres permet de choisir l'arabe l'anglais ou le français la visionneuse HTML ou simple la traduction dans la page ou dans une fenêtre séparée ainsi que l'apparence claire ou sombre

Vos choix sont conservés pour le prochain démarrage

Mises à jour sans ouvrir de navigateur

L'application vérifie GitHub Releases après le démarrage et vous pouvez lancer une vérification manuelle depuis Aide puis Rechercher des mises à jour

Lorsqu'une version est disponible Mettre à jour maintenant ouvre une fenêtre interne qui indique sa version sa date de publication une barre de progression et le pourcentage

Le programme d'installation approprié est téléchargé dans le dossier de mises à jour de Power Accessible Mail du profil utilisateur son empreinte SHA-256 est vérifiée puis le programme d'installation apparaît dans une fenêtre visible avant la fermeture de l'application pour terminer la mise à jour et redémarrer

Guide détaillé de la fenêtre principale

Notifications de l'application

La barre de notification apparaît en haut de la fenêtre et annonce les informations importantes comme la réussite d'une opération une nouvelle connexion nécessaire ou une mise à jour disponible. Certaines notifications disparaissent après un court délai tandis que la barre d'état en bas conserve l'état de la dernière opération

Sélecteur de compte de messagerie

Ce contrôle affiche les comptes ajoutés. La sélection d'un compte remplace les dossiers et les messages affichés sans mélanger ses données avec celles d'un autre compte. Si aucun compte n'existe ouvrez Options et gestion des comptes pour en ajouter un

Liste des commandes de l'application

Actualiser le contenu affiché récupère les messages les plus récents de la section actuelle et effectue la même action que F5

Synchroniser tous les messages continue à récupérer les anciens courriels par lots et les stocke localement jusqu'à la fin ou l'arrêt de la synchronisation

Charger des messages plus anciens récupère un lot antérieur aux messages actuellement affichés dans la section

Options et gestion des comptes ouvre les commandes permettant d'ajouter un compte de se reconnecter ou de supprimer le compte

Composer un courriel ouvre la fenêtre de création d'un message

Paramètres ouvre les choix concernant la langue de l'application la visionneuse de messages le mode de traduction et l'apparence

Sections de la messagerie

Boîte de réception Courrier indésirable Messages envoyés et Tous les messages sont des pages indépendantes avec leurs propres messages et leur propre filtre. Tous les messages est disponible lorsque le fournisseur le prend en charge et peut révéler des messages qui ne portent pas le libellé Boîte de réception

Choix du filtre

Le filtre détermine ce que la section actuelle affiche : Tous Favoris Non lus Lus ou le véritable dossier Corbeille. La sélection de Corbeille demande son contenu réel au fournisseur de messagerie

Liste des messages

Chaque ligne contient État Expéditeur Sujet et Date. L'état indique si le message est lu ou non lu suivi ou épinglé. Utilisez les touches fléchées Origine Fin Page précédente et Page suivante pour naviguer. La sélection d'un message charge son contenu mais ne modifie pas automatiquement son état de lecture

Visionneuse de messages

Cette zone affiche le message sélectionné avec la visionneuse HTML ou simple choisie dans Paramètres. Échap ramène le focus à la liste des messages et Ctrl+Entrée ouvre la visionneuse des éléments

Visionneuse des éléments

Cette liste séparée rassemble les liens les boutons les images et les pièces jointes du message. Chaque élément commence par son type et son numéro comme Lien 1 Bouton 1 Image 1 ou Pièce jointe 1 puis indique son nom et son adresse ou le type et la taille du fichier. L'application regroupe les adresses équivalentes après normalisation de l'hôte et des paramètres de suivi courants puis choisit la meilleure description parmi le texte de l'élément aria-label title ou alt. Les liens et les boutons conservent l'ordre de lecture puis viennent les images et les pièces jointes. Les images de suivi masquées de 1 par 1 sont exclues

Bouton Actions de l'élément

Ce bouton affiche directement les commandes sans sous-menu : Ouvrir la pièce jointe sélectionnée Enregistrer la pièce jointe sélectionnée Enregistrer toutes les pièces jointes en une fois Ouvrir l'image Enregistrer l'image Ouvrir le lien sélectionné et Copier le lien sélectionné. Répondre Suivre Traduire Épingler et Supprimer restent dans le menu contextuel du message

Progression de la récupération et barre d'état

La barre de progression indique le pourcentage de récupération ou de synchronisation. La barre d'état annonce l'opération actuelle et son résultat sans qu'il soit nécessaire d'y déplacer le focus

Marquer un message comme lu ou non lu

Se déplacer sur un message ou ouvrir son contenu ne le marque pas comme lu. Dans la liste normale des messages appuyez une fois sur Espace pour basculer le message ciblé entre lu et non lu. La colonne État change immédiatement puis l'application enregistre cet état sur le serveur

Lorsqu'un message est non lu vous pouvez appuyer sur la touche Applications ou Maj+F10 puis choisir Marquer comme lu. Le menu contextuel ne contient pas Marquer comme non lu; utilisez Espace dans la liste des messages pour changer l'état de lecture. En mode de sélection multiple Marquer comme lu est disponible pour le groupe sélectionné

Utilisez le filtre Non lus pour retrouver les messages qui demandent encore votre attention et le filtre Lus pour revoir les messages terminés

Utiliser la visionneuse des éléments étape par étape

Lorsque le focus se trouve dans la visionneuse de messages appuyez sur Ctrl+Entrée. La visionneuse des éléments devient disponible et le focus se place dans sa liste. Utilisez les flèches Haut et Bas pour choisir un lien un bouton une image ou une pièce jointe

Appuyez sur Entrée ou Espace pour ouvrir directement l'élément. Un lien sûr ou une image avec une adresse externe s'ouvre dans l'application appropriée et une pièce jointe s'ouvre localement. Un bouton doté d'un lien se comporte de la même manière tandis qu'un bouton ou une image sans adresse ni données utilisables est annoncé clairement

Pour obtenir des commandes explicites appuyez sur Tab pour atteindre le bouton Actions de l'élément puis sur Entrée ou Espace. Une pièce jointe propose les commandes d'ouverture et d'enregistrement une image propose Ouvrir l'image et Enregistrer l'image et un lien propose les commandes d'ouverture et de copie. Les commandes qui ne correspondent pas au type de l'élément restent désactivées afin d'éviter une activation accidentelle

Appuyez sur Ctrl+Entrée pour revenir à la visionneuse de messages ou sur Échap pour revenir directement à la liste des messages. La liste des éléments n'a pas de menu contextuel. Le bouton Actions de l'élément est le seul endroit qui affiche ces commandes et les présente directement sans sous-menu

Gérer les pièces jointes reçues

L'ouverture d'une pièce jointe crée une copie temporaire protégée portant un nom sûr puis demande à Windows de l'ouvrir dans l'application par défaut. Les copies temporaires créées pour la session actuelle sont supprimées à la fermeture de Power Accessible Mail

Avant d'ouvrir un fichier susceptible d'exécuter des commandes comme EXE BAT CMD ou MSI l'application affiche un avertissement de sécurité avec Non comme choix par défaut. Continuez uniquement si vous faites confiance à l'expéditeur et au fichier

Pour enregistrer une seule pièce jointe ciblez-la dans la visionneuse des éléments puis allez au bouton Actions de l'élément et choisissez Enregistrer la pièce jointe sélectionnée avant de choisir son nom et son dossier. Pour tout enregistrer choisissez Enregistrer toutes les pièces jointes en une fois avec le même bouton et sélectionnez un seul dossier. Pour enregistrer une image ciblez-la puis choisissez Enregistrer l'image. Pour copier un lien ciblez-le puis choisissez Copier le lien sélectionné. Lorsqu'un nom existe déjà l'application crée un nom unique au lieu de remplacer silencieusement le fichier précédent

Composer un message et ajouter des pièces jointes sortantes

La fenêtre de composition commence par les champs À puis Sujet et Corps sur plusieurs lignes. La liste Pièces jointes ajoutées suit le Corps et le bouton Ajouter une pièce jointe suit cette liste. La liste se trouve donc entre le contenu du message et le bouton dans l'ordre de tabulation

Appuyez sur Ajouter une pièce jointe pour ouvrir le sélecteur de fichiers. Vous pouvez choisir un seul fichier ou plusieurs fichiers au cours de la même opération. Chaque fichier choisi apparaît dans la liste avec son nom et sa taille afin que vous puissiez vérifier exactement ce qui sera envoyé

Pour retirer un fichier ajouté par erreur ciblez-le dans la liste des pièces jointes et appuyez sur Suppr ou sur la touche Applications puis choisissez Retirer la pièce jointe sélectionnée. Le retrait de la liste ne supprime jamais le fichier original de votre ordinateur

Lorsque vous appuyez sur Envoyer l'application ajoute tous les fichiers encore affichés dans la liste au message MIME. Cette fonction est disponible pour les comptes Gmail API et SMTP. Le fournisseur de messagerie fixe les limites de taille du message et des pièces jointes et peut refuser un message qui dépasse la taille autorisée

Menus contextuels et touche Applications

La touche Applications du clavier est parfois appelée Menu ou Menu contextuel. Elle ouvre le menu contextuel du contrôle qui possède le focus. Power Accessible Mail la prend en charge dans la liste des messages la visionneuse de messages le bouton Actions de l'élément et la liste des pièces jointes sortantes. La liste de la visionneuse des éléments n'a pas de menu contextuel; appuyez sur Tab pour atteindre Actions de l'élément. Maj+F10 est équivalent lorsqu'un menu contextuel est disponible

Le menu contextuel de la visionneuse de messages propose Répondre Marquer comme lu si nécessaire Suivre Traduire Épingler et Supprimer. Le bouton Actions de l'élément affiche directement les sept commandes des pièces jointes des images et des liens sans sous-menu. Pour les atteindre appuyez sur Ctrl+Entrée afin de passer à la visionneuse des éléments sélectionnez un élément puis appuyez sur Tab pour atteindre Actions de l'élément

Dans la liste des messages les commandes s'adaptent au message ciblé et à son état actuel. Sur le bouton Actions de l'élément elles s'adaptent au type de l'élément sélectionné. En mode de sélection multiple les commandes de message agissent sur le groupe et l'application indique le nombre de messages concernés avant la suppression

Commandes clavier utiles

Ctrl+A ouvre les options et la gestion des comptes
Ctrl+N compose un nouveau message
Ctrl+R répond au message ciblé
Ctrl+T traduit le message actuel
F5 actualise les messages
F1 ouvre le guide de l'application
Échap revient à la liste des messages depuis la visionneuse de messages ou la visionneuse des éléments
Ctrl+Entrée passe de la visionneuse de messages à la visionneuse des éléments
Maj+F10 ouvre le menu contextuel et le menu Actions
Alt+F4 ferme l'application

La protection de vos données fait partie de la conception

L'accès OAuth commence uniquement après votre autorisation sur la page officielle du fournisseur

Les messages mis en cache localement les jetons et les identifiants enregistrés sont protégés par Windows DPAPI pour le compte Windows actuel

Les paquets de distribution ne contiennent ni comptes ni messages d'utilisateurs

La suppression d'un compte depuis l'application supprime également les données locales de ce compte conservées par l'application
