1.6.0 版的主要操作流程

按 Alt+1 进入当前分类的邮件列表，按 Alt+2 返回您真正打开过的最后一封邮件的阅读器，按 Alt+3 进入邮件区域，按 Alt+4 进入程序命令列表。Alt+D 打开完整的快捷键指南。列表旁显示的预览不算已打开邮件；您必须先进入邮件阅读器。如果以前没有打开过阅读器，Alt+2 会提示您先打开一封邮件。

“设置”提供三种搜索方式。Ctrl+F 打开独立的搜索窗口；搜索按钮提供发件人和日期筛选；永久搜索框会在输入时筛选当前区域。搜索只使用所选账户中当前已加载的邮件，并匹配发件人、地址、主题、日期和状态。它不会搜索完整正文，也不会直接搜索仍仅位于服务器上的全部邮件。查找旧邮件前，请先加载更早的邮件或执行全部同步。

归档会将邮件移出收件箱，但不会送入回收站。在邮件列表中打开上下文菜单并选择“归档邮件”。之后可在“已归档邮件”分类中找到它，需要时选择“返回收件箱”。置顶和归档命令位于邮件列表的菜单中；阅读器内的菜单不包含全部列表命令。

按 Ctrl+Enter 打开项目查看器。用方向键选择链接、图片或附件，然后按应用程序键或 Shift+F10 打开该项目的菜单，也可以按 Tab 移到“项目操作”按钮。Ctrl+Enter 返回邮件，Escape 返回邮件列表。

在写信窗口的“收件人”中输入或粘贴地址，然后启用将该地址添加到通讯录的按钮。您可以按原样保存地址，也可以指定自定义名称。保存后仍停留在写信窗口。以后可在“收件人”字段按向下箭头，选择保存的名称并按 Enter 或空格；字段内容将被相应的电子邮件地址替换。

只有当焦点位于邮件阅读器内时，Ctrl+T 才会翻译收到的邮件。首次使用时，请接受隐私说明，并从以 20 种常用语言开头的列表中选择目标语言。旧版本会自动选择阿拉伯语，因此以前已允许翻译的用户也需要选择一次语言。翻译语言与界面语言相互独立。

若要在发送前翻译，请在主题或正文中打开上下文菜单，并选择将文本转换为其他语言。添加语言只会保存该语言，不会立即翻译；请再次打开菜单并选择该语言。整个字段会被替换，按 Ctrl+Z 可恢复原文。

Alt+H 打开交互式指南。它包含 31 个使用本地练习数据的任务，不会发送真实邮件或修改您的账户，并会保存进度。新任务涵盖多选菜单、文件夹、自定义分区和本地分类。程序更新准备好后，应用会关闭并启动正常的交互式安装窗口；请按照安装页面完成更新，更新不会静默安装。

搜索消息

在“设置”中选择您喜欢的搜索方式。按需搜索可使用 Ctrl+F 打开一个完整的窗口，在阿拉伯语键盘布局上显示为 Ctrl+party。您可以改为在类别旁边显示一个按钮，或者在您键入时显示一个永久字段来过滤当前部分。

搜索窗口包含结果列表、消息查看器和项目查看器。它搜索应用程序已加载或同步的消息，并匹配发件人姓名、电子邮件地址、主题、日期和状态。

邮件部分

已发送的收件箱垃圾邮件和所有邮件是单独的页面，具有自己的显示消息和过滤器。当提供商支持时，所有邮件均可用，并且可能会显示不带有收件箱标签的邮件

过滤器选择

过滤器控制当前部分显示的内容：所有已加星标的未读已读或真正的垃圾文件夹。选择“垃圾箱”会向电子邮件提供商请求其实际内容

留言列表

每行包含状态发件人主题和日期。状态宣布邮件是否已读或未读，已加星标或已固定。使用箭头键 Home End Page Up 和 Page Down 进行导航。选择消息会加载其内容，但不会自动更改其阅读状态

消息查看器

该区域使用 HTML 或在“设置”中选择的简单查看器显示所选消息。 Escape 将焦点返回到消息列表，Ctrl+Enter 移动到项目查看器

项目查看器

这个单独的列表收集消息链接按钮图像和附件。每个项目都以其类型和编号开头，例如链接 1 按钮 1 图片 1 或附件 1，后跟其名称和地址或文件类型和大小。应用程序在规范化主机和通用跟踪参数后组合等效地址，并从元素文本 aria-label 标题或 alt 文本中选择最佳描述。链接和按钮保持阅读顺序，然后是图像和附件。排除隐藏的 1 x 1 跟踪图像

项目操作按钮

邮件列表的菜单包含阅读状态、星标、置顶、归档、删除和整理操作。邮件阅读器的专用菜单包含回复、复制、翻译和转发。项目查看器有独立的链接、图片和附件菜单。

消息检索进度和状态栏

进度控制报告消息检索或同步百分比。状态栏宣布当前操作及其结果，因此您无需将焦点移至其上

将消息标记为已读或未读

阅读状态取决于设置中选择的模式。自动模式下，进入邮件查看器会将邮件标记为已读；仅选中列表中的邮件行不会标记。手动模式下，打开查看器不会改变阅读状态。在普通邮件列表中，Space 在已读和未读之间切换，程序随后将更改保存到服务器。

按应用程序菜单键或 Shift+F10 打开上下文菜单。多选模式下，阅读状态命令位于子菜单中，作用于选中的邮件。

使用“未读”过滤器查找仍需要注意的邮件，使用“已读”过滤器查看已完成的邮件

逐步使用项目查看器

对于显式命令，请按 Tab 键到达“项目操作”按钮，然后按 Enter 或 Space。附件提供“打开选定的附件”和“保存选定的附件”，您可以一次保存邮件中的每个附件。具有外部地址的链接或图像提供“打开选定的链接”和“复制选定的链接”，将其安全地址放在 Windows 剪贴板上。不适用于所选项目的命令保持禁用状态，以防止意外激活

按 Ctrl+Enter 打开项目查看器。用方向键选择链接、图片或附件，然后按应用程序键或 Shift+F10 打开该项目的菜单，也可以按 Tab 移到“项目操作”按钮。Ctrl+Enter 返回邮件，Escape 返回邮件列表。

管理收到的附件

如果邮件服务商允许接收，应用可下载单个最大 5 GB（5,000,000,000 字节）的已收附件。下载分块进行，不会把整个大附件载入内存。请选择有足够空间且支持大文件的磁盘，并等待下载完成。下载失败时，不会用不完整的副本替换已有文件。发送上限和图片显示的 25 MB 上限保持不变；云存储链接指向的文件不在此范围内。
打开附件会使用安全名称写入受保护的临时副本，并要求 Windows 在默认应用程序中打开它。当 Power Accessible Mail 关闭时，为当前会话创建的临时副本将被删除

在打开可能运行 EXE BAT CMD 或 MSI 等命令的文件之前，应用程序会显示安全警告，默认为“否”。仅当您信任发件人和文件时才继续

要保存一个附件，请将其聚焦在项目查看器中，然后移至“项目操作”按钮并选择“保存所选附件”，然后再选择其名称和文件夹。要保存每个附件，请从同一按钮中选择一次保存所有附件，然后选择一个文件夹。要复制链接焦点，请使用项目操作并选择复制所选链接；应用程序将其安全地址放置在 Windows 剪贴板上。当文件名已经存在时，应用程序会创建一个唯一的名称，而不是默默地替换以前的文件

撰写消息并添加传出附件

撰写窗口以“收件人”开头，然后是“将电子邮件地址添加到地址簿”，然后是“主题”和多行正文字段。添加附件位于正文后面，后面是添加的附件列表，然后按 Tab 键顺序发送和取消

当焦点位于“要”时，按向下箭头打开保存的地址。使用方向键移动并按 Enter 或 Space 选择一项；所选地址将替换该字段中的所有文本。如果您在该字段为空或无效时按下“添加地址”按钮，应用程序会报告该问题并且不会保存它

按添加附件打开文件选择器。您可以在同一操作中选择一个文件或多个文件。每个选定的文件及其文件名和大小都会显示在列表中，以便您可以准确查看将发送的内容

要删除错误添加的文件，请将其聚焦在附件列表中，然后按删除或按应用程序键并选择删除选定的附件。从列表中删除它永远不会从您的计算机中删除原始文件

当您按“发送”时，应用程序会将列表中仍然显示的每个文件添加到 MIME 消息中。这适用于 Gmail API 和 SMTP 帐户。电子邮件提供商控制邮件和附件的大小限制，并可能拒绝超过其允许大小的邮件

使用地址簿

从应用程序命令列表中打开地址簿。添加新电子邮件地址旁边会出现垂直地址列表。使用箭头键浏览，然后按 Enter 或空格键或双击地址以打开“撰写”，并自动填写收件人

在地址上按应用程序键或 Shift+F10 可打开其上下文菜单。您可以编辑电子邮件地址或将其固定在顶部；对于固定地址，命令将更改为从顶部取消固定电子邮件地址。您还可以查看发送给它和从它接收的消息或将其删除。在关联消息窗口中，使用箭头键移动并按 Enter 或 Space 键以在主窗口中打开所选消息

应用程序键（菜单键）或 Shift+F10 打开当前焦点控件的菜单。邮件、文件夹、区域、查看器、待发送附件和地址簿条目各有自己的菜单。请先将焦点移到需要操作的项目上。

邮件阅读器菜单提供回复、复制、翻译和转发。更改阅读状态、添加星标、置顶、归档或删除，请返回邮件列表。操作链接、图片或附件时，按 Ctrl+Enter 打开项目查看器，使用它的菜单或“项目操作”按钮。

在消息列表中，命令适应焦点消息及其当前状态。在“项目操作”按钮上，它们会适应所选的项目类型。在多选择模式下，消息命令作用于组，并且应用程序在删除之前说明受影响的消息计数

消息文件夹和本地部分

文件夹对您选择的消息进行分组。自定义部分是消息和文件夹的本地位置。既不会创建服务器文件夹，也不会在您的提供商处移动邮件。在邮件列表中按 Alt+Z，使用箭头键和空格键选择邮件，然后按 Tab 键创建文件夹或取消。输入姓名；将其留空将使用带有今天日期的新文件夹。消息中间会出现一个文件夹，其中包含名称、消息计数和创建日期。按 Enter 键将其打开，然后按 Backspace 键返回。其消息在分组时隐藏在常规列表中。文件夹上下文菜单提供固定、加星标、重命名、存档和恢复。删除文件夹仅删除分组，而不删除其消息。

Alt+X 将选定的邮件添加到现有文件夹。上下文命令将消息添加到文件夹或部分可让您选择任一目标。在文件夹内，您可以将邮件移出文件夹，而不删除邮件本身。 Alt+C 删除焦点文件夹。 Alt+Ctrl+Z 创建一个节； Alt+Ctrl+X 将焦点项目移动到本地某个部分； Alt+Ctrl+C 删除当前自定义部分而不删除原始邮件。内置部分无法删除。 要将邮件移回原来的区域，请在其菜单中选择“返回原始部分”。

自定义类别是过滤器

打开类别框上的上下文菜单并选择“创建新类别”，或按 Alt+Ctrl+Shift+Z。使用箭头和 Enter 选择一个过滤器，然后输入名称。该类别出现在跨邮件部分的熟悉的类别框中，并过滤加载的本地邮件；它不是目的地。过滤器包括最近阅读、促销邮件、组织、指定发件人地址、频繁发件人、锁定邮件、邮件文件夹、带附件的邮件和不带附件的邮件。来自发件人域的组织检测估计；它不验证发件人的身份。对于指定的发件人，请在命名类别之前输入地址。

Ctrl+向下移动到自定义类别； Ctrl+Up 返回到第一个内置类别。 Alt+Ctrl+Shift+X 编辑当前自定义过滤器，Alt+Ctrl+Shift+C 删除它。删除过滤器不会删除邮件。锁定消息过滤器不会绕过密码。

文件夹和分区的密码锁

在消息文件夹或自定义部分中，打开上下文菜单并选择密码锁。阅读警告，输入至少八个字符并确认密码。程序从常规列表和搜索结果中隐藏这些邮件，并使用密码和当前 Windows 用户的保护，加密其分组关系和本地缓存内容。本地 Windows 帐户可以使用；不需要 Microsoft 帐户。

在锁定的项目上按 Enter 键并输入其密码以查看该文件夹或部分中的内容。离开其范围或切换帐户会关闭解锁的会话。要永久删除保护，请选择删除锁定并输入密码。没有密码恢复功能。邮件仍保留在提供商处，但本地组织可能无法恢复。锁定不保护先前导出、下载或备份的副本或提供商帐户。本地加密数据与 Windows 用户相关，不应假定可移植到其他用户或计算机。使用磁盘加密并保护您的 Windows 会话。

声音和低视力选项

在设置中打开“自定义应用声音”。 单独启用或禁用事件，然后在声音名称上按 Enter 或单击它进行预览。替换接受 MP3 文件。确认声音对话框和设置以保存更改；取消不会覆盖您之前保存的声音。更新和安装程序背景音乐是​​固定的，此处不可自定义。安装程序有一个静音复选框。

设置中的“低视力功能和选项”位于“自定义应用声音”之后。 本机选择框和复选框提供文本和界面缩放、对比度、焦点突出显示、应用程序内指针和文本/背景颜色。使用 Tab、箭头和 Space，确认对话框，然后保存设置。这些选项会更改应用程序的外观，而不是屏幕阅读器的设置。

其他导航和选择快捷方式
Alt+S 打开地址簿。Alt+] 切换到下一个账户，Alt+[ 切换到上一个账户；在阿拉伯语键盘上分别对应 د 和 ج。Alt+A 打开账户管理，Ctrl+A 选择当前显示的邮件，不选择文件夹。在文本输入框之外，Backspace 后退一步。Escape 先退出邮件文件夹或多选模式，并提示再次按下以返回主界面；在查看器中，Escape 返回邮件列表。在本指南中，1 跳到下一标题，2 跳到上一标题。Alt+D 打开快捷键指南。

锁定地址簿文件夹

按 Alt+S 打开地址簿，在文件夹选项中选择创建文件夹，用方向键和 Space 选择地址，再按 Tab 移到创建按钮并输入名称。文件夹显示在同一个地址列表中，其中的地址不会在外部重复显示。Enter 打开文件夹，Backspace 返回。菜单提供置顶、重命名、密码锁定以及保留地址并删除文件夹；没有归档或星标功能。在文件夹内，可以通过文件夹选项将地址移出而不删除它。新保存的地址留在当前列表，并加入正在打开的文件夹。

在地址簿中打开文件夹的上下文菜单，选择密码锁定。锁定保护姓名、地址和置顶状态，不保护联系人的邮件。按 Enter 并输入密码打开文件夹。即使文件夹已打开，其中的地址也不会出现在通用收件人列表中。您可以在文件夹内添加、编辑、置顶或删除地址。仅将地址移出文件夹而不删除它，会使该地址重新出现在公共地址簿中。移除锁定后，地址仍保留在文件夹中，并可在通用收件人列表中选择。

移除账户之前，请先移除地址簿文件夹的锁定。如果地址也位于另一个账户的对话文件夹中，必须先将其从那个文件夹中移出，才能锁定。忘记的密码无法恢复，保存在程序之外的副本不受保护。
