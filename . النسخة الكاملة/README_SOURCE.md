# مصدر النسخة الكاملة

هذا المجلد هو ملف تعريف النسخة الكاملة، وليس نسخة مستقلة من المصدر. ملف `run.bat` يشغل المصدر المشترك الموجود في جذر المشروع باستخدام هوية النسخة الكاملة وملف `oauth_clients.json` الموجود هنا.

ملف البناء هنا يحيل إلى أداة البناء المشتركة في الجذر. لبناء النسخة شغل:

```powershell
.\build_power_accessible_mail_64.ps1
```

ملف المثبت المعتمد هو `..\installer_power_accessible_mail.iss` في جذر المشروع، وهو الذي يتضمن اللغتين وملخص الخصوصية ومربع الموافقة.
