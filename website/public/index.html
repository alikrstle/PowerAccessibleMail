Power Accessible Mail

A Windows email client built around blind users: clear navigation, comfortable reading, and direct commands without hunting through crowded screens.

حين يصبح البريد الإلكتروني قابلاً للاستخدام فعلاً

كثير من برامج البريد تعمل جيداً لمن يرى الشاشة، لكنها تتحول مع قارئ الشاشة إلى رحلة طويلة بين عناصر غير واضحة. Power Accessible Mail يحاول حل هذه المشكلة من أساسها، لا بوضع طبقة وصول فوق برنامج عادي، بل ببناء تجربة بريد مكتبية تفهم طريقة عمل المستخدم الكفيف.

Email that stays out of your way

A stable vertical interface, direct commands, and two message viewers let each user choose the reading experience that works best.

تنقل يعرف أين أنت

يعتمد البرنامج على عناصر Windows الأصلية حتى ينطقها قارئ الشاشة بوضوح، ويحافظ قدر الإمكان على موضع التركيز أثناء تحديث البريد أو تبديل الحسابات.

طريقتان لقراءة الرسالة

يمكنك فتح الرسالة كما جاءت ببنيتها وروابطها، أو الانتقال إلى عرض نصي أبسط عندما يكون هدفك قراءة المحتوى بسرعة بعيداً عن فوضى التنسيق.

حساباتك في مكان واحد

يدعم Gmail وMicrosoft عبر تسجيل الدخول الرسمي، كما يتيح إضافة الحسابات اليدوية عبر IMAP وSMTP لمن يحتاج إلى مزود بريد آخر.

تنظيم الرسائل دون إرهاق

بدلاً من التعامل مع كل رسالة وحدها، تستطيع تحديد أكثر من رسالة وتنفيذ الإجراء المناسب عليها، مثل النقل أو الحذف أو تغيير حالة القراءة.

ترجمة عند الحاجة فقط

إذا وصلت رسالة بلغة لا تفضّلها، يمكنك طلب الترجمة بنفسك. لا يرسل البرنامج نصوص الرسائل للترجمة في الخلفية ولا يتصرف نيابة عنك.

تحديثات أوضح

يعرض المحدث رقم الإصدار وتاريخ النشر ونسبة التنزيل، حتى يعرف المستخدم ما يحدث بدلاً من انتظار صامت أو فتح صفحات خارجية غير مريحة.

Clear screen-reader navigation

Native Windows lists and controls keep focus stable while mail synchronizes or accounts change.

HTML and easy viewers

Read the original message structure and links, or use a simplified text view with fewer empty lines.

Gmail and Microsoft

Official browser sign-in, plus manual IMAP and SMTP accounts when needed.

Multiple selection

Turn the message list into checkboxes, select what you need, and apply an appropriate bulk action.

Optional translation

Translate message content in place or in a separate window. Translation starts only when you request it.

In-app updates

The updater shows the version, release date, and download progress without opening a web page.

ليس بديلاً شكلياً، بل تجربة استخدام مختلفة

الفكرة ليست أن يكون لديك برنامج بريد جديد فقط، بل أن تصبح المهام اليومية قابلة للتنفيذ بثقة: فتح البريد، معرفة الرسائل الجديدة، قراءة النص والروابط، حفظ المرفقات، الرد، ثم العودة إلى القائمة دون أن يضيع التركيز أو تتداخل العناصر.

لذلك تم بناء Power Accessible Mail بلغة Python وبواجهة wxPython، مع اهتمام خاص بطريقة نطق العناصر، وترتيب التنقل، واستقرار الشاشة أثناء العمل.

ما الذي يلاحظه المستخدم؟

  • أسماء عناصر أوضح لقارئات الشاشة.
  • قائمة رسائل يمكن فهمها والتنقل داخلها بلوحة المفاتيح.
  • خيارات مباشرة للرد والإرسال والروابط والمرفقات.
  • تقليل المفاجآت أثناء المزامنة أو تحديث الحساب.

A different daily email experience

The goal is not simply to add another email app. It is to make everyday tasks feel reliable: open mail, find new messages, read content and links, save attachments, reply, and return to the list without losing context.

Power Accessible Mail is built with Python and wxPython, with careful attention to control names, navigation order, and focus stability.

What users should notice

  • Clearer control names for screen readers.
  • A message list that works well from the keyboard.
  • Direct actions for replies, links, and attachments.
  • Fewer surprises during sync and account refresh.

خصوصية البريد ليست هامشاً صغيراً

لأن البريد الإلكتروني قد يحتوي على العمل والدراسة والحسابات والرسائل الشخصية، صُمم البرنامج ليتصل مباشرة بمزود البريد الذي تختاره. لا يمر محتوى رسائلك أو مرفقاتك أو رموز تسجيل الدخول عبر خوادم المطور.

اقرأ سياسة الخصوصية الكاملة

بوضوح: ماذا يحدث لبياناتك؟

  • يخزن نسخة محلية مؤقتة من الرسائل لتسريع القراءة ويشفرها باستخدام Windows DPAPI.
  • يستخدم Gmail API بنطاق gmail.modify لتقديم وظائف البريد التي تختارها.
  • يرسل نص الرسالة إلى Google Translate فقط عندما تطلب الترجمة.

Your email data stays on your device

The app connects directly to the mail services you choose. It does not send your messages, attachments, or sign-in tokens to the developer's servers.

Read the full Privacy Policy

What does the app do?

  • Stores an encrypted local message cache using Windows DPAPI.
  • Uses Gmail API with the gmail.modify scope for the email actions you choose.
  • Sends message text to Google Translate only when you request translation.
