Privacy Policy

This policy explains what data Power Accessible Mail uses, why it is used, and how it remains under the user's control.

آخر تحديث: 27 يوليو 2026

نبذة

Power Accessible Mail برنامج بريد إلكتروني مكتبي لنظام Windows، مصمم للمكفوفين ومستخدمي قارئات الشاشة. يتيح ربط حساب Gmail أو Microsoft، وقراءة الرسائل، واستعراض الروابط والمرفقات، والرد، والإرسال، وتنظيم البريد.

طريقة تطوير البرنامج

تمت عمليات البرمجة والتطوير بمساعدة تقنية VIP Coding، وكانت أداة Codex من الأدوات المستخدمة في كتابة الشيفرة ومراجعتها. يخص ذلك عملية تطوير البرنامج فقط، ولا يعني أن رسائل المستخدمين أو حساباتهم أو رموز تسجيل الدخول تُرسل إلى Codex عند استخدام البرنامج.

بيانات Google التي يصل إليها البرنامج

عند ربط حساب Gmail، يطلب البرنامج نطاق https://www.googleapis.com/auth/gmail.modify إضافة إلى معلومات الهوية الأساسية اللازمة لتمييز الحساب. يستخدم البرنامج Gmail API مباشرة ولا يطلب نطاق https://mail.google.com/.

قد يصل البرنامج إلى عنوان البريد الإلكتروني والملف الشخصي الأساسي، ورؤوس الرسائل، والمرسل والموضوع والتاريخ وحالة القراءة، ونصوص الرسائل، والروابط والمرفقات، ومجلدات البريد التي يختار المستخدم عرضها.

كيفية استخدام بيانات Google

  • عرض صندوق البريد والرسائل داخل البرنامج.
  • قراءة الرسائل في مستعرض HTML أو المستعرض السهل.
  • عرض الروابط والمرفقات الموجودة في الرسالة.
  • تغيير حالة القراءة، ووضع النجمة، ونقل الرسائل المحددة إلى سلة Gmail.
  • إرسال رسائل جديدة وردود باسم المستخدم.
  • حفظ نسخة محلية مشفرة لتحسين السرعة وتقليل إعادة تنزيل البيانات.

لا يستخدم Power Accessible Mail بيانات Google للإعلانات أو التحليلات أو بناء الملفات الشخصية أو تدريب الذكاء الاصطناعي أو البيع لأي طرف.

بيانات Microsoft والحسابات اليدوية

عند اختيار Microsoft، يستخدم البرنامج تسجيل الدخول الرسمي عبر OAuth للوصول إلى البريد من خلال IMAP وSMTP وفق موافقة المستخدم. وعند إضافة حساب يدوي، تستخدم بيانات الخادم وتسجيل الدخول التي يدخلها المستخدم للاتصال بمزود البريد المختار فقط.

التخزين المحلي والحماية

تخزن بيانات التطبيق على جهاز Windows الخاص بالمستخدم. تُشفّر ذاكرة الرسائل المحلية ونصوص الرسائل وروابطها ومرفقاتها وملخصاتها باستخدام Windows DPAPI المرتبط بحساب Windows الحالي. تحفظ رموز OAuth محلياً حتى لا يحتاج المستخدم إلى تسجيل الدخول في كل تشغيل.

مشاركة البيانات والخدمات الخارجية

لا يرسل البرنامج محتوى Gmail أو Microsoft أو المرفقات أو رموز OAuth إلى خوادم المطور.

عندما يطلب المستخدم ترجمة رسالة صراحة، يُرسل النص المحدد إلى Google Translate لتنفيذ الترجمة فقط. الترجمة اختيارية ولا تعمل في الخلفية. ويتصل البرنامج بـ GitHub Releases للتحقق من توفر إصدار جديد وتنزيله، من دون تضمين أي محتوى من البريد.

الاحتفاظ بالبيانات وحذفها

تبقى بيانات البريد المحلية ما دام المستخدم يحتفظ ببيانات التطبيق على جهازه. يمكن حذفها بإزالة الحساب من البرنامج أو حذف المجلد %APPDATA%\PowerAccessibleMail. كما يستطيع المستخدم إلغاء وصول Google أو Microsoft من صفحة أذونات حسابه لدى مزود الخدمة.

الاستخدام المحدود لبيانات Google

يلتزم استخدام Power Accessible Mail للمعلومات المستلمة من Google APIs ونقلها بسياسة Google API Services User Data Policy بما في ذلك متطلبات Limited Use.

Overview

Power Accessible Mail is a Windows desktop email client designed for blind and screen-reader users. It lets users connect Gmail or Microsoft accounts, read messages, browse links and attachments, reply, send, and organize email.

Development method

The app was developed with the assistance of VIP Coding, and Codex was one of the tools used to write and review code. This describes the development process only. It does not mean that users' email messages, accounts, or sign-in tokens are sent to Codex when the app is used.

Google user data accessed

When a user connects Gmail, the app requests https://www.googleapis.com/auth/gmail.modify and the basic identity information needed to identify the account. It uses Gmail API directly and does not request https://mail.google.com/.

The app may access the email address and basic profile, message headers, sender, subject, date, read state, message bodies, links, attachments, and mail folders the user chooses to view.

How Google user data is used

  • Display the mailbox and messages inside the app.
  • Read messages in the HTML viewer or easy viewer.
  • Show links and attachments contained in messages.
  • Change read state, star messages, and move user-selected messages to Gmail Trash.
  • Send new messages and replies on the user's behalf.
  • Keep an encrypted local cache for faster loading and fewer repeated downloads.

Power Accessible Mail does not use Google user data for advertising, analytics, profiling, AI training, or sale to any party.

Microsoft and manual account data

When Microsoft is selected, the app uses the official OAuth sign-in flow to access mail over IMAP and SMTP with the user's consent. For a manual account, the server and sign-in information entered by the user is used only to connect to the selected email provider.

Local storage and security

Application data is stored on the user's Windows device. The local message cache, message bodies, links, attachments, and summaries are encrypted with Windows DPAPI and tied to the current Windows account. OAuth tokens are stored locally so the user does not have to sign in every time.

Data sharing and external services

The app does not send Gmail or Microsoft message content, attachments, or OAuth tokens to the developer's servers.

When the user explicitly requests translation, the selected text is sent to Google Translate only to perform that translation. Translation is optional and never runs in the background. The app also contacts GitHub Releases to check for and download updates, without including any email content.

Retention and deletion

Local email data remains while the user keeps the application data on the device. It can be deleted by removing the account in the app or deleting %APPDATA%\PowerAccessibleMail. Users can also revoke Google or Microsoft access from their provider's account permissions page.

Google Limited Use

Power Accessible Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
