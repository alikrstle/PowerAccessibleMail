# قائمة تحقق قبل إرسال طلب Google OAuth

## المتطلبات العامة

- [ ] لديك نطاق Domain تملكه.
- [ ] تم التحقق من النطاق في Google Search Console.
- [ ] توجد صفحة رئيسية للتطبيق على النطاق نفسه.
- [ ] توجد سياسة خصوصية على النطاق نفسه.
- [ ] صفحة البرنامج تذكر اسم Power Accessible Mail ووظيفته بوضوح.
- [ ] سياسة الخصوصية تشرح الوصول إلى Gmail والتخزين المحلي والتشفير والحذف.
- [ ] بريد الدعم يعمل ويمكنك استقبال رسائل Google عليه.

## داخل Google Cloud Console

- [ ] اسم التطبيق: Power Accessible Mail.
- [ ] نوع المستخدم: External.
- [ ] App domain / Homepage مضبوط.
- [ ] Privacy policy URL مضبوط.
- [ ] Developer contact email مضبوط.
- [ ] Authorized domains تحتوي على نطاقك.
- [ ] OAuth Client من نوع Desktop app أو مناسب للبرنامج المكتبي.
- [ ] Redirect URI المحلي يعمل مع البرنامج.
- [ ] النطاقات المعلنة تطابق ما يطلبه البرنامج.

## النطاقات الحالية

- [ ] `openid`
- [ ] `email`
- [ ] `profile`
- [ ] `https://www.googleapis.com/auth/gmail.modify`

## فيديو العرض

- [ ] يوضح تسجيل الدخول من داخل البرنامج.
- [ ] يوضح شاشة موافقة Google كاملة.
- [ ] يوضح قراءة الرسائل.
- [ ] يوضح الروابط والمرفقات.
- [ ] يوضح إرسال رسالة أو الرد.
- [ ] يوضح دليل البرنامج/الخصوصية داخل الواجهة.
- [ ] لا يحتوي على بيانات شخصية حقيقية.

## بعد الإرسال

- [ ] راقب بريد مالك المشروع ومحرريه.
- [ ] كن مستعدا لشرح استخدام `gmail.modify` للقراءة والإرسال وإدارة حالة الرسائل وسلة المحذوفات.
- [ ] كن مستعدا لاحتمال طلب تقييم أمني بسبب نطاق Gmail المقيد.
